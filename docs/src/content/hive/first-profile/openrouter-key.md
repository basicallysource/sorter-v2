Hive's assistant, the **Assistant** tab in the profile editor, runs on your own OpenRouter account. Hive does not sell AI credit, and your card details stay with OpenRouter.

1. Make an account at [openrouter.ai](https://openrouter.ai).
2. Add credits at [openrouter.ai/credits](https://openrouter.ai/credits). It is prepaid, not a subscription. Building a profile costs a few cents.
3. Create a key at [openrouter.ai/keys](https://openrouter.ai/keys) and copy it. It starts with `sk-or-v1-` and is shown only once.
4. In Hive, open **Settings**, paste it into **OpenRouter key** in the **AI assistant** panel, and save. The badge beside the field changes from **None** to **Saved**.

The key is stored encrypted and is only used when you ask the assistant for something. **Remove the key** in the same panel deletes it.

Without a key you can still build a profile by adding rules by hand in the editor, or by pointing [an assistant you already use]({{ '/hive/first-profile/ask-in-plain-words/#an-assistant-you-already-use' | relative_url }}) at Hive, which needs no OpenRouter key.
