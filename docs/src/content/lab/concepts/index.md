A concept is a proposal for changing the standard Sorter V2 that has not been built. That is the difference from a [tested variant]({{ '/lab/variants/' | relative_url }}), which somebody has made and run on their own machine. A concept page says what is measured and what is estimated, so the claims in it can be checked before anyone prints anything.

None of these is part of the build instructions in [Hardware]({{ '/hardware/' | relative_url }}), and none is in the parts calculator.
